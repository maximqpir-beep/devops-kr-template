# Контрольная работа №1: Git и валидаторы

Добавлена проверка российского телефона `validate_phone`, сохранены `validate_email` и функция преподавателя `validate_snils`.

## Проверка

Из корня проекта (Python 3, внешние зависимости не нужны):

```bash
python -m unittest discover -s tests -v
```

## Этапы и скриншоты

См. [инструкцию](REPORT_GUIDE.md). В `evidence/stages.bundle` сохранена настоящая локальная Git-история: четыре исходных коммита, результат interactive rebase и разрешённое слияние. Текстовые выводы и копии файла до/после конфликта находятся в `evidence/`.

GitHub-копия опубликована через API: содержимое совпадает с локальным результатом, но SHA опубликованных коммитов отличаются из-за метаданных автора/времени. Архив хранит исходные SHA выполненных локально операций.

Основная ветка исходного шаблона называлась `master`; при переносе на GitHub она переименована в `main`. Тесты из `test/` перенесены в `tests/`, добавлен отсутствовавший импорт. При слиянии были разрешены конфликт в `validator.py` и конфликт удаления/изменения старого тестового файла; итоговые тесты находятся в `tests/`.

Настройку внешнего зеркала и скриншоты необходимо завершить на компьютере студента по инструкции.
